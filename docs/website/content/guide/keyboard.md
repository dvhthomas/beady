## The command palette

{{< k "⌘P" >}} runs any command or jumps to a bead by its id or title.

{{< shot name="palette" alt="The command palette: a search field above a list of commands with their shortcuts and categories." caption="Every command, with its shortcut." >}}

It really is any command: views, filters, layouts, columns, themes, text size, pins, stars,
focus, back and forward, saving and resetting a view, switching workspace, settings.

It answers to the words you'd type rather than only the names on the menus. `fin` finds
Find, `kanban` finds the board, `blocked` finds Stuck, `drac` finds the Dracula theme, and
`switch to` followed by a name changes workspace.

## Shortcuts

Press {{< k "?" >}} in the app for the full list.

### Finding

| Key | Does |
|---|---|
| {{< k "⌘P" >}} | Command palette |
| {{< k "/" >}} | Search the current view |
| {{< k "F" >}} | Filter |
| {{< k "⇧V" >}} | Display options |
| {{< k "⌘1" >}} {{< k "⌘2" >}} {{< k "⌘3" >}} | List, Board, Tree |
| {{< k "⌘I" >}} | Show or dock the details pane |
| {{< k "⌘G" >}} | Dependency graph |
| {{< k "Esc" >}} | Let go of the selection, or close floating details |

### Changing

| Key | Does |
|---|---|
| {{< k "⌘N" >}} | New bead |
| {{< k "⌘E" >}} | Edit the selected bead |
| {{< k "⇧⌘P" >}} | Pin or unpin |
| {{< k "⇧⌘S" >}} | Star or unstar |
| {{< k "⌘Z" >}} | Undo a change to a bead |

### Views

| Key | Does |
|---|---|
| {{< k "⌘S" >}} | Save the view |
| {{< k "⌥⌘S" >}} | Save as a new view |
| {{< k "⌥⌘R" >}} | Reset the view to how it was saved |

### The app

| Key | Does |
|---|---|
| {{< k "⌘O" >}} | Open a workspace |
| {{< k "⌃⌘O" >}} | Cycle through recent workspaces |
| {{< k "⌘R" >}} | Refresh from bd |
| {{< k "⌘T" >}} | Theme picker |
| {{< k "⌘," >}} | Settings |

The single-key shortcuts ({{< k "/" >}}, {{< k "F" >}}, {{< k "?" >}}) only fire when you
aren't typing in a field.
